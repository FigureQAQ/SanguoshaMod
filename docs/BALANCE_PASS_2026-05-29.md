# 2026-05-29 全卡牌平衡调整

## 调整目标

- 保留三国杀模组“略高于官方卡牌”的强度，但削弱无条件抽牌、免费能量、永久力量/敏捷和高额格挡的叠加。
- 稀有牌继续承担构筑核心，普通牌和非核心锦囊回到更稳定的数值区间。
- 装备强度更多来自触发条件和战斗节奏，不再靠大量直接永久属性解决所有问题。

## 主要改动

- 基础牌：`杀`、`闪`、`桃`、`酒`整体降档；`桃`移除能量收益，`酒`改为基础 1 费、升级后 0 费。
- 锦囊牌：`无中生有`改为基础 1 费，`决斗`、`南蛮入侵`、`万箭齐发`、`闪电`、`桃园结义`等爆发牌下调基础数值和升级增幅。
- 能力牌：`空城`、`龙胆`、`制衡`、`连营`、`奸雄`、`鬼才`降低无条件格挡、抽牌和下一张杀的爆发，保留核心机制。
- 装备牌：`贯石斧`、`大宛`、`麒麟弓`、`铁索连环`、`古锭刀`的杀增伤链整体下调；`古锭刀`从伤害翻倍改为 150%。
- 扩展牌：`刺杀`、`守势`、`仁德`、`突袭`下调效率，其中 `仁德`改为基础 1 费、升级后 0 费。

## 同步范围

- 实际卡牌效果：`LiveScripts/Cards/*.cs`。
- 装备与能力事件：`LiveScripts/Characters/SanguoshaCharacterSkills.cs`。
- 本地化文案：`LiveScripts/Patches/SanguoshaLocalizationPatches.cs`。
- 卡面生成数据：`tools/cardgen/core-cards.json`、`tools/cardgen/trick-cards.json`、`tools/cardgen/equipment-cards.json`。

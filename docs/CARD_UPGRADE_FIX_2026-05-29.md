# 2026-05-29 卡牌升级效果修复

- 补齐 `奇袭` 的升级效果：提高易伤数值，并提高升级后抽牌收益。
- 补齐 `蛇矛杀` 的自身升级效果：若被事件、遗物或其他系统直接升级，伤害和抽牌收益会正常成长。
- `蛇矛杀` 现在同时识别自身升级和 `丈八蛇矛` 装备升级状态，避免生成牌被外部升级时没有实际收益。
- `太平要术` 的 `TurnHeal` 动态数值现在会随升级同步增长，牌面数值与实际回合回血一致。
- `藤甲` 已从受击触发格挡改为回合开始固定格挡与自损生命；`绝影` 的实际触发格挡同步为当前平衡后的数值，避免升级前后仍使用旧版高格挡。
- 已扫描 `LiveScripts/Cards` 下所有 `OnUpgrade()`，当前没有空升级函数。

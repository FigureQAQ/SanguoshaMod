# 装备牌说明

本文档记录当前装备牌的槽位、玩法定位和换装触发效果。装备分为武器、防具、坐骑、宝物四个槽位；同槽位只能保留一件，新装备会顶掉旧装备，并触发旧装备的“失去时”效果。

## 武器

- 诸葛连弩：获得力量并生成免费杀。每回合开始时让手牌中前若干张杀本回合变为 0 费。失去时按本回合已打出的杀抽牌。
- 丈八蛇矛：抽牌，并在手牌足够时补 1 张 0 费蛇矛杀。蛇矛杀可消耗任意两张其他手牌当杀打出。失去时获得能量并补蛇矛杀。
- 青釭剑：获得能量。杀无视敌人格挡。失去时获得能量。
- 贯石斧：获得力量和能量。杀命中有格挡的敌人时追加伤害。失去时获得力量并强化下一张杀。
- 寒冰剑：抽牌。杀命中后施加虚弱。失去时抽牌。
- 麒麟弓：获得力量并抽牌。杀命中已有负面效果的敌人时追加伤害并施加易伤。失去时获得力量并抽牌。
- 古锭刀：获得力量。杀命中无格挡目标时造成 150% 伤害。失去时获得力量。
- 干将莫邪：获得力量并抽牌。每回合前几次杀命中后追加剑气伤害。失去时强化下一张杀并抽牌。

## 防具

- 八卦阵：敌人攻击时从抽牌堆顶依次打出牌；若为闪则获得格挡并继续，直到不是闪或攻击已被完全格挡。失去时抽牌并获得格挡。
- 仁王盾：获得敏捷。失去时获得敏捷。
- 白银狮子：获得敏捷并回复生命。每回合开始回复生命，每回合单次受伤有上限。失去时回复生命。
- 藤甲：获得敏捷。敌人非杀伤害来临前获得格挡。失去时获得格挡。

## 坐骑

- 赤兔：获得力量和能量。失去时获得能量，并使手牌中的杀临时变为 0 费。
- 大宛：获得力量。失去时获得力量，并强化下一张杀。
- 的卢：获得敏捷。失去时获得敏捷和格挡。
- 绝影：获得敏捷。每回合首次敌人即将造成伤害时获得格挡。失去时获得格挡。

## 宝物

- 玉玺：获得能量、力量并抽牌。每回合开始额外获得能量。失去时获得能量并抽牌。
- 木牛流马：获得能量并抽牌。每回合前若干次打出锦囊牌后抽牌。失去时抽牌。
- 太平要术：获得敏捷并回复生命。每回合开始净化负面效果，成功净化时获得能量并额外回复生命。失去时回复生命。
- 孟德新书：获得能量并抽牌。每回合首次打出锦囊牌后获得能量，并使杀或锦囊牌本回合变为 0 费。失去时获得能量并临时减费。

## 本次新增

- 干将莫邪：补武器槽的“杀连段增伤”方向，适合多杀、无双、丈八蛇矛和酒的爆发回合。
- 藤甲：补防具槽的“非杀防护”方向，和八卦阵的闪判定形成区别。
- 绝影：补坐骑槽的“每回合一次保命”方向，适合低血量或空城流。
- 孟德新书：补宝物槽的“锦囊转节奏”方向，让锦囊牌能带动杀牌和后续锦囊的减费。

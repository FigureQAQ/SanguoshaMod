# 2026-05-29 杀附魔与易伤节奏调整

本轮目标是降低杀附魔的无条件滚雪球能力，尤其避免赤壁猛将和麒麟弓把易伤变成常驻覆盖。

- 赤壁猛将 / 火杀：命中后追加伤害从旧版 3 点下调为 2 点；生命不高于一半时追加伤害为 4 点，并且每回合首次火杀才施加 1 层易伤。
- 麒麟弓：杀命中已有负面效果的敌人仍会追加伤害，但易伤改为每回合首次符合条件的命中才触发。
- 锦囊夜行 / 毒杀：命中后中毒从 4 层下调为 3 层，保留攻击已中毒目标时每回合首次回能。
- 机关卧龙 / 雷杀：命中后雷击伤害收窄为目标 1 点、其他敌人 2 点，保留雷势满 4 后的全体爆发。
- 汉室仁主 / 储能杀：命中后的号令追加伤害从 `2 + 至多 4 点号令` 下调为 `1 + 至多 3 点号令`，保留储能满 2 后回能抽牌。

这些改动都通过玩家回合开始时重置的状态位控制，避免引入随机或客户端差异，适合联机同步。

# 三国杀卡牌词条策略

当前模组不再注册“控场、强攻、武技”等仅用于分类、没有独立规则效果的自定义黄色词条。
牌面只保留真正由系统处理的关键词，例如原生的“消耗”。卡牌的风味名、机制名和分类说明应写在普通描述里，不再做成 hover 词条。

## 2026-05-25 机制边界

- “锦囊牌”是文案层对 `CardType.Skill` 的称呼；不额外注册黄色词条。
- “能力牌”和“装备”分开处理：空城、制衡、无双属于能力；武器、防具、坐骑、宝物属于装备槽系统。
- 装备槽仍保持武器、防具、坐骑、宝物各最多 1 件，替换同槽装备时触发卸下逻辑和图标刷新。
- 能力牌可以显示 buff 图标，但不进入装备槽，也不会顶掉武器、防具、坐骑或宝物。
- 丈八蛇矛不再通过“打出锦囊牌后生成免费杀”触发，改为生成隐藏虚拟牌“蛇矛杀”，由玩家消耗任意 2 张其他手牌当杀打出。
- 部分锦囊升级后会移除原生“消耗”关键词，例如观星、无中生有、铁索连环、无懈可击。

## 2026-05-25 装备/能力图标路径

- 装备与能力显示用的 power icon 不再走 `ImageHelper.GetImagePath("power_icons/...")`，因为该 helper 会解析到游戏 `res://images/...`，无法命中部署在 `mods/sanguosha/power_icons` 下的 PNG。
- `SanguoshaPowerIconAssets` 会注册 RitsuLib 外部 provider，并直接从当前 mod DLL 所在目录读取 `power_icons` / `power_icons_big` 下的 PNG，作为防止 UI 回退到 `NOPE` 的兜底路径。

## 2026-05-25 八卦阵与遗物兼容

- 八卦阵不再提供敏捷；它现在接入原版 `Hook.BeforeDamageReceived`，在敌人攻击扣格挡前从抽牌堆顶连续判定。
- 判定到 `闪` 时，将该牌移入弃牌堆并获得格挡；若攻击已被完全格挡则停止，否则继续判定。判定到非 `闪` 也会移入弃牌堆并停止。
- 八卦阵升级后 0 费，并将每张判定 `闪` 的格挡量从 6 提升到 8。
- 原版遗物 `TuningFork`（中文表现为齿轮/玻璃相关遗物）对三国杀 `CardType.Skill` 锦囊牌增加兼容分支，避免全局卡池替换后计数和触发丢失。

## 2026-05-25 锦囊机制多样化

- 新增的“判定”不是黄色词条，而是实际从抽牌堆顶翻出 1 张牌并置入弃牌堆的通用动作；兵粮寸断、乐不思蜀、闪电、铁索连环已使用该动作。
- 火攻改为可弃 1 张手牌，并按弃牌费用、稀有度和类型改变伤害/中毒/易伤，避免继续落入固定伤害模板。
- 借刀杀人和决斗会真实消耗手牌中的 `杀` 来换取额外段数或额外伤害，没有杀时提供较弱的抽牌保底。
- 顺手牵羊改为偷取目标格挡并给自己等量格挡；若无格挡可偷，则改为把手牌临时变为 0 费，形成和过河拆桥不同的节奏定位。
- 铁索连环保留本回合 `杀` 的连环溅射事件，同时增加判定后的即时连环收益；升级后仍通过原生 `消耗` 关键词变化体现强度。

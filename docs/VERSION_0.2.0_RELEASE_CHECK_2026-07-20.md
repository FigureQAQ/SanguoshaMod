## 本次重构

- 新增 35 张简洁联动型卡牌。
- 每名角色新增两张硬专属起始牌，且不进入奖励池。
- 新增共享杀流、负面状态流、弃牌/消耗流、防守蓄力流和装备轮换流组件。
- 新增刚烈、闭月、狂风、断肠、颂威五张角色稀有能力与方天画戟。
- 简化调度、苦肉、蓄势、破阵、布防、南蛮入侵、万箭齐发、过河拆桥、无中生有。
- 五张 Boss 形态各自只保留一个回合循环主题。
- 调整火攻、突袭、奇袭、刮骨疗毒及指定装备/能力牌稀有度。

## 资源

- 35 张新牌均有 `1024×752` PNG 卡图。

## 启动审计修复

- 修复 C# 回退本地化字典存在重复键、可能在静态初始化阶段抛出异常的问题。
- 将全部中文 JSON 作为程序集资源嵌入，并优先作为运行时回退文本来源。
- 修复武圣、活墨在构造函数中修改关键词导致的 `CanonicalModelException`。
- 删除 STS2 `0.109.0` 已不存在的 `CardPileCmd.Add` Harmony 重载补丁。
- 修复方天画戟把正在打出的杀误判为“其他攻击牌”的边界。
- 防止颂威在能力牌自身尚未完成打出时触发自身收益。
- 为卡牌生成药水、卡牌相关遗物和事件补充 Owner/玩家为空时的原版回退保护。
- 药水生成统一使用角色奖励池过滤，不会生成起始牌、Boss牌、生成牌、其他角色专属牌或单人禁用牌。
- 攻击、技能、能力、无色、宇宙调和物和奥罗酸药水在自定义牌池不可用时回退原版效果，避免药水被消耗却无事发生。
